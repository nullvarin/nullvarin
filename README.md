# Null

Software engineer. Most of my work is in Rust and Swift, with TypeScript when a project needs it.

I build command-line tools, macOS applications, and developer tooling. Most of it stays private until it's finished, then goes public when I'm satisfied with it.

## Stack

Rust for CLI tools, systems software, and anything that needs to run everywhere. Serenity for Discord bots.

Swift for macOS. That's where I spend most of my time when I'm not in Rust.

TypeScript for web projects and bots, usually with Astro, and discord.js for Discord.

I'm learning C and C++ at the moment. I want a better grip on what's actually happening below the level I normally work at.

## Interests

Systems programming, developer tooling, compilers. Long-term I want to build a programming language. Design, parser, compiler, runtime. I have a rough idea of what it needs and no idea what it looks like yet.

## Currently Building

**[Malus](https://github.com/nullvarin/malus)** — A fast macOS system fetch tool written in Swift. Extracts deep system info in ~20ms, supports JSON output, and runs completely native on Apple Silicon.
